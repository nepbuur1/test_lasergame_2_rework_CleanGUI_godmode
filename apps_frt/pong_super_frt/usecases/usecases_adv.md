# Super Pong

## Introductie

Doel is het ontwerpen van een wat uitgebreidere variant van het spel pong.

## Use Cases

| UC01_Main    |                                                                                                                                                                                                                                                    |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving | Coordineren wat het programma doet op het hoogste niveau: zijn we in het startscherm, spelen we het spel of zijn we in de game over afhandeling.                                                                                                   |
| Scenario     | 1. Het startscherm wordt afgehandeld (zie UC02_GameStarting).<br/>2. De speler wordt in staat gesteld het spel te spelen (zie UC04_GamePlaying).<br/>3. De game over wordt afgehandeld (zie UC04_GameOverHandling).<br/>4. Terug naar stap 1.<br/> |

| UC02_GameStarting |                                                                                                                               |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving      | Splash ervaring bij start van het spel geven.                                                                                 |
| Preconditie       | De main usecase (UC01_Main) heeft beslist dat dit nu moet gebeuren.                                                           |
| Scenario          | 1. De titel van het spel wordt getoond.<br/>2. Er is een "Start Game" knop zichtbaar.<br/>3. Wacht tot die knop is ingedrukt. |
| Invariant         | Toon voor de sfeer een paar geanimeerde toortsen aan de zijkant van het scherm.                                               |
| Postconditie      | Keer terug naar UC01_Main.                                                                                                    |

| UC03_GameOverHandling |                                                                                                                                                                                                                                                                                                                                                                |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving          | Game over afhandeling.                                                                                                                                                                                                                                                                                                                                         |
| Preconditie           | De main usecase (UC01_Main) heeft beslist dat dit nu moet gebeuren.                                                                                                                                                                                                                                                                                            |
| Scenario              | 1. Als de score een top-5 plek heeft verdiend:<br/>  a. Toon een invoerveld met erboven "type uw naam".<br/>  b. Wacht op de invoer compleet (na ENTER)<br/>  c. Sla de bijgewerkte top-5 op in spif geheugen.<br/>2. Toon de hall of fame (top 5).<br/>    a. Met daaronder de knop "Play Again"<br/>3. Wacht op het indrukken van die "Play Again" knop<br/> |
| Invariant             | Toon voor de sfeer een paar geanimeerde toortsen aan de zijkant van het scherm.                                                                                                                                                                                                                                                                                |
| Postconditie          | Keer terug naar UC01_Main.                                                                                                                                                                                                                                                                                                                                     |

| UC04_GamePlaying |                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving     | De organisatie van het spel besturen.                                                                                                                                                                                                                                                                                                                                                                                                               |
| Preconditie      | De main usecase (UC01_Main) heeft beslist dat dit nu moet gebeuren.                                                                                                                                                                                                                                                                                                                                                                                 |
| Scenario         | 1. Toon het spelbord<br/>2. Zet score op 0.<br/>3. Activeer de paddle<br/>4. Spawn een bal in het midden met random richting omhoog.<br/>5. Wacht tot er geen ballen meer in het spel zijn. (elke bal die de onderlijn waar de paddle langs beweegt, passeert, is uit het spel)<br/>6. Toon "Game Over" over het startscherm.<br/>2. Na klikken op het Game Over label of het verstrijken van 3 seconden (wat eerst is), keer terug naar UC01_Main. |
| Invariant        | Als er gedurende 3 seconden geen bal de onderlijn is gepasseerd, wordt de volgende beslissing genomen:<br/>Een vuurkorf spawnen of een present crate spawnen. De kans op dat de keus op een vuurkorf valt is evenredig met het aantal ballen in het veld (meer dan 40 ballen betekent altijd een vuurkorf). Als het geen vuurkorf wordt, dan valt de keuze op een present crate (zie UC08_FireBinHandling en UC07_PresentHandling)                  |
| Postconditie     | Er is terugekeerd naar UC01_Main.                                                                                                                                                                                                                                                                                                                                                                                                                   |

| UC05_BallHandling |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving      | Het gedrag van de bal besturen                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Preconditie       | De bal is gespawned door UC01_Main of UC07_PresentHandling.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Scenario          | 1. De bal verplaatst zich elk frametijdinterval een stapje in zijn voortbewegingsrichting.<br/>  a. Als het daarbij een muur of paddle raakt, verandert zij          van richting, zodat het op ketsen lijkt.<br/>      In geval van de paddle wordt de score verhoogd.<br/>  b. Als het onder de onderlijn komt, "verbrandt de bal" in een animatie. Vervolgens verbergt/deactiveert hij zich.  <br/>  c. Als het een Present Crate  raakt, geeft het dat     door aan het betreffende object.<br/> d. Als het een vuurkorf raakt, vliegt de bal in brandt. Hij brandt dan op in 3 seconden. |
| PostConditie      | De bal is verborgen/gedeactiveerd/klaar voor toekomstig gebruik.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |

| UC06_PaddleHandling |                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving        | Het gedrag van de paddle besturen                                                                                                                                                                                                                                                                                                                                                                                                  |
| Preconditie         | De paddle is geactiveerd door UC04_GamePlaying                                                                                                                                                                                                                                                                                                                                                                                     |
| Scenario            | 1. Wacht tot een toets ingedrukt is<br/>2. Als het de knop voor links is: <br/>    a. start bewegen van de paddle naar links. <br/>    b. Blijf dat elke frameintervaltijd doen totdat de betreffende toets weer losgelaten is.<br/>3. Als het de knop voor rechts is: <br/>    a. Start bewegen van de paddle naar rechts. <br/>    b. Blijf dat elke frameintervaltijd doen totdat de betreffende toets weer losgelaten is.<br/> |

| UC07_PresentHandling |                                                                                                                                                                                                                                                                                                                                  |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving         | Het gedrag van een present crate besturen.                                                                                                                                                                                                                                                                                       |
| Preconditie          | De present crate is gespawned door UC04_GamePlaying.                                                                                                                                                                                                                                                                             |
| Scenario             | 1. Initialiseer counter op 5.<br/>2. Wacht tot een bal de present crate raakt.<br/>3. Verlaagt de counter.<br/>4. Als de counter groter dan 0 is, ga naar 1.<br/>5. Haal de betreffende present crate uit het spel en spawn 10 extra ballen op de betreffende plek.<br/>(elk van die ballen draait de usecase UC05_BallHandling) |

| UC08_FireBinHandling |                                                                                              |
| -------------------- | -------------------------------------------------------------------------------------------- |
| Beschrijving         | Het gedrag van een fire bin besturen.                                                        |
| Preconditie          | De fire bin is gespawned door UC04_GamePlaying.                                              |
| Scenario             | 1. Wacht ongeveer 5 seconden.<br/>2. Haal de betreffende present fire bin weer uit het spel. |

| UC09_NameInputHandling |                                                                                                                                                 |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving           | Een naam in laten typen                                                                                                                         |
| Preconditie            | Deze usecase wordt gestart door UC03_GameOverHandling                                                                                           |
| Scenario               | 1. Toon een invoerveld met erboven "type uw naam".<br/>2. Activeer een touchscreen-keyboard.<br/>3. Wacht op de invoer compleet (na ENTER)<br/> |
| Invariant              | Het touchscreen-keyboard update het invoerveld naar gelang van de ingetypte toetsten.                                                           |
| Postconditie           | Keer terug naar UC03_GameOverHandling                                                                                                           |
