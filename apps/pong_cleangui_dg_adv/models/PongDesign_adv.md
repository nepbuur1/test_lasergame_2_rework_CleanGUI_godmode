# Pong

## Introductie

Doel is een eenvoudige voorbeeldgame, pong.

## Use Cases

| UC01_Main    |                                                                                                                                                                                                                                                    |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving | Coordineren wat het programma doet op het hoogste niveau: zijn we in het startscherm, spelen we het spel of zijn we in de game over afhandeling.                                                                                                   |
| Scenario     | 1. Het startscherm wordt afgehandeld (zie UC02_GameStarting).<br/>2. De speler wordt in staat gesteld het spel te spelen (zie UC04_GamePlaying).<br/>3. De game over wordt afgehandeld (zie UC04_GameOverHandling).<br/>4. Terug naar stap 1.<br/> |

| UC02_GameStarting |                                                                                                                               |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving      | Splash ervaring bij start van het spel geven.                                                                                 |
| Preconditie       | De main usecase (UC01_Main) heeft beslist dat dit nu moet gebeuren.                                                           |
| Scenario          | 1. De titel van het spel wordt getoond.<br/>2. Er is een "Start Game" knop zichtbaar.<br/>3. Wacht tot die knop is ingedrukt. |
| Postconditie      | Keer terug naar UC01_Main.                                                                                                    |

Nog leuke "Nice to Haves" om bovenstaand eventueel later toe te voegen:

- Opluisteren met animaties (van de Titel zelf, of tierelantijntjes erbij)

| UC03_GameOverHandling |                                                                                                                     |
| --------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Beschrijving          | Game over afhandeling.                                                                                              |
| Preconditie           | De main usecase (UC01_Main) heeft beslist dat dit nu moet gebeuren.                                                 |
| Scenario              | 1. Laat de tekst "Game Over zien".<br/>2. Wacht op een aanraking van het scherm of een timeout van 10 seconde.<br/> |
| Postconditie          | Keer terug naar UC01_Main.                                                                                          |

Nog leuke "Nice to Haves"" om bovenstaand eventueel later toe te voegen:

- Opluisteren met animaties (van de text Game Over zelf, of tierelantijntjes erbij).
- Een high score list laten zien.
- Bij voldoende score de speler zijn naam laten invoeren, om de high score list te updaten.

| UC04_GamePlaying |                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving     | De organisatie van het spel besturen.                                                                                                                                                                                                                                                                                                                                                                           |
| Preconditie      | De main usecase (UC01_Main) heeft beslist dat dit nu moet gebeuren.                                                                                                                                                                                                                                                                                                                                             |
| Scenario         | 1. Toon het spelbord<br/>2. Activeer de padlle<br/>3. Spawn een bal met random richting omhoog.<br/>4. Wacht tot er geen ballen meer in het spel zijn. (elke bal die de onderlijn waar de paddle langs beweegt, passeert, is uit het spel)                                                                                                                                                                      |
| Invariant        | Als er gedurende 3 seconden geen bal de onderlijn is gepasseerd, wordt de volgende beslissing genomen:<br/>Een mine spawnen of een present crate spawnen. De kans op dat de keus op een mijn valt is evenredig met het aantal ballen in het veld (meer dan 40 ballen betekent altijd een mijn). Als het geen mijn wordt, dan valt de keuze op een present crate (zie UC05_MineHandling en UC07_PresentHandling) |
| Postconditie     | Keer terug naar UC01_Main.                                                                                                                                                                                                                                                                                                                                                                                      |



| UC07_PresentHandling |                                                                                                                                                                                                                                           |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving         | Het gedrag van een present crate besturen.                                                                                                                                                                                                |
| Preconditie          | De present crate is gespawned door UC04_GamePlaying.                                                                                                                                                                                      |
| Scenario             | 1. Telkens als een bal de present crate raakt, verlaagt de counter ervan.(die begint op 5).<br/>2. Wacht tot de counter 0 bereikt.<br/>3. Haal de betreffende present crate uit het spel en spawn 10 extra ballen op de betreffende plek. |

| UC06_PaddleHandling |                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving        | Het gedrag van de paddle besturen                                                                                                                                                                                                                                                                                                                                                                                                  |
| Preconditie         | De paddle is geactiveerd door UC04_GamePlaying                                                                                                                                                                                                                                                                                                                                                                                     |
| Scenario            | 1. Wacht tot een toets ingedrukt is<br/>2. Als het de knop voor links is: <br/>    a. start bewegen van de paddle naar links. <br/>    b. Blijf dat elke frameintervaltijd doen totdat de betreffende toets weer losgelaten is.<br/>3. Als het de knop voor rechts is: <br/>    a. start bewegen van de paddle naar rechts. <br/>    b. Blijf dat elke frameintervaltijd doen totdat de betreffende toets weer losgelaten is.<br/> |

| UC05_BallHandling |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving      | Het gedrag van de bal besturen                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Preconditie       | De bal is gespawned door UC01_Main of UC07_PresentHandling.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Scenario          | 1. De bal verplaatst zich elk frametijdinterval een stapje in zijn voortbewegingsrichting.<br/>  a. Als het daarbij een muur of paddle raakt, verandert zij          van richting, zodat het op ketsen lijkt.<br/>      In geval van de paddle wordt de score verhoogd.<br/>  b. Als het onder de onderlijn komt, "verbrandt de bal" in een animatie. Vervolgens verbergt/deactiveert hij zich.  <br/>  c. Als het een Present Crate  raakt, geeft het dat     door aan het betreffende object.<br/> d. Als het een vuurkorf raakt, vliegt de bal in brandt. Hij brandt dan op in 3 seconden. |
| PostConditie      | De bal is verborgen/gedeactiveerd/klaar voor toekomstig gebruik.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
