# Pong

## Introductie

Doel is een eenvoudige voorbeeldgame: pong, met een bal en een peddel op het
touchscreen van de CYD. Het is een deelverzameling van Super Pong
(`apps/pong_super`): geen score, geen hall of fame, geen vuurkorven of present
crates, en altijd maar een bal tegelijk. De nummering van de use cases volgt die
van Super Pong, zodat dezelfde use case in beide hetzelfde nummer heeft.

## Use Cases

| UC01_Main    |                                                                                                                                                                                                                                     |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving | Coordineren wat het programma doet op het hoogste niveau: zijn we in het startscherm, spelen we het spel of zijn we in de game over afhandeling.                                                                                    |
| Scenario     | 1. Het startscherm wordt afgehandeld (zie UC02_GameStarting).<br/>2. De speler wordt in staat gesteld het spel te spelen (zie UC04_GamePlaying).<br/>3. De game over wordt afgehandeld (zie UC03_GameOverHandling).<br/>4. Terug naar stap 2. |

| UC02_GameStarting |                                                                                                                                         |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving      | Het startscherm tonen.                                                                                                                  |
| Preconditie       | De main usecase (UC01_Main) heeft beslist dat dit nu moet gebeuren. Dat gebeurt alleen bij het opstarten.                              |
| Scenario          | 1. De titel van het spel, "Pong", wordt getoond.<br/>2. Er is een knop "Click here to Start" zichtbaar.<br/>3. Wacht tot die knop is ingedrukt. |
| Postconditie      | Keer terug naar UC01_Main.                                                                                                              |

| UC03_GameOverHandling |                                                                                                                                               |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving          | Game over afhandeling.                                                                                                                        |
| Preconditie           | De main usecase (UC01_Main) heeft beslist dat dit nu moet gebeuren.                                                                           |
| Scenario              | 1. Toon het label "GAME OVER".<br/>2. Toon daaronder de knop "Click here to Start".<br/>3. Wacht op het indrukken van die knop.                 |
| Postconditie          | Keer terug naar UC01_Main.                                                                                                                    |

| UC04_GamePlaying |                                                                                                                                                                                                                                                                 |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving     | De organisatie van het spel besturen.                                                                                                                                                                                                                           |
| Preconditie      | De main usecase (UC01_Main) heeft beslist dat dit nu moet gebeuren.                                                                                                                                                                                             |
| Scenario         | 1. Toon het spelbord: de muren links, rechts en boven, de doellijn, de bal en de peddel, met de knoppen voor links en rechts.<br/>2. Activeer de peddel (zie UC06_PaddleHandling).<br/>3. Start de bal (zie UC05_BallHandling).<br/>4. Wacht tot de peddel de bal gemist heeft.<br/>5. Deactiveer de peddel en verberg het spelbord. |
| Postconditie     | Keer terug naar UC01_Main.                                                                                                                                                                                                                                      |

| UC05_BallHandling |                                                                                                                                                                                                                                                                                                                                                                                                       |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving      | Het gedrag van de bal besturen.                                                                                                                                                                                                                                                                                                                                                                       |
| Preconditie       | De bal is gestart door UC04_GamePlaying.                                                                                                                                                                                                                                                                                                                                                              |
| Scenario          | 1. De bal begint in het midden van het veld, met een willekeurige richting naar links of rechts.<br/>2. De bal verplaatst zich elk frametijdinterval (25 keer per seconde) een stapje in zijn voortbewegingsrichting.<br/>  a. Als hij daarbij een muur raakt, ketst hij af.<br/>  b. Als hij de peddel raakt, ketst hij af. Hoe verder van het midden van de peddel, hoe schuiner.<br/>3. Als hij helemaal voorbij de doellijn is, meldt de bal dat de peddel hem gemist heeft, en stopt hij. |
| Postconditie      | De bal staat stil, klaar om opnieuw gestart te worden.                                                                                                                                                                                                                                                                                                                                                |

| UC06_PaddleHandling |                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beschrijving        | Het gedrag van de peddel besturen.                                                                                                                                                                                                                                                                                                                                                                                                 |
| Preconditie         | De peddel is geactiveerd door UC04_GamePlaying.                                                                                                                                                                                                                                                                                                                                                                                    |
| Scenario            | 1. Wacht tot een toets ingedrukt is.<br/>2. Als het de knop voor links is: <br/>    a. Start bewegen van de peddel naar links. <br/>    b. Blijf dat elke frameintervaltijd doen totdat de betreffende toets weer losgelaten is.<br/>3. Als het de knop voor rechts is: <br/>    a. Start bewegen van de peddel naar rechts. <br/>    b. Blijf dat elke frameintervaltijd doen totdat de betreffende toets weer losgelaten is.<br/> |
| Invariant           | De peddel blijft tussen de muren.                                                                                                                                                                                                                                                                                                                                                                                                  |
| Postconditie        | Na deactivatie door UC04_GamePlaying is de peddel verborgen.                                                                                                                                                                                                                                                                                                                                                                       |
